## English

> JSONViz is a free, browser-based JSON visualizer that turns raw JSON into an interactive, searchable tree. No signup, no server, no data leaves your browser.

### ✨ Features

- **🌳 Interactive Tree View** — Expand, collapse, drill into nested data
- **🔍 Search & Filter** — Find any key or value instantly
- **🎨 Syntax Highlighting** — Color-coded types (string, number, boolean, null, array, object)
- **📸 Export as PNG** — Screenshot your tree for docs, Slack, or presentations
- **✨ Beautify & Minify** — Format messy JSON or compress it in one click
- **📋 One-click Copy** — Copy formatted JSON to clipboard
- **🔒 100% Client-side** — Your data never leaves the browser
- **💜 Free Forever** — No signup, no limits

### 🎯 Who is this for?

- **Developers** debugging API responses
- **Data analysts** exploring JSON datasets
- **QA engineers** inspecting payloads
- **Students** learning JSON structure
- **Anyone** who thinks raw JSON is unreadable

### 🛠 Usage

1. Open [JSONViz](https://tyr1105.github.io/json-viz/)
2. Paste or type your JSON
3. Click **Visualize** to explore the tree
4. Use search, expand/collapse, or export as needed

### ⚙️ Tech Stack

- Vanilla HTML/CSS/JS — zero framework
- Pure DOM rendering — no virtual DOM overhead
- Zero dependencies, zero server, zero tracking
